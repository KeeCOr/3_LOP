|---|---|---|---|---|
| 높음 | 타일 지형 텍스처 4종 | 512x512 PNG | 숲, 해안, 산악, 황무지 타일 배경 | 미생성 |
| 높음 | 이벤트/찬스 카드 일러스트 | 1024x1024 PNG | 이벤트 모달, 카드 보상 연출 | 미생성 |

| 중간 | 승리/패배 결과 배경 | 16:9 PNG | 게임 종료 화면 폴리싱 | 미생성 |
| 낮음 | UI 패널 장식 코너/프레임 | 256x256 PNG 또는 CSS/SVG | 금장 패널 반복 장식 | 코드/CSS 대체 가능 |

## 생성 프롬프트 요약

- 보드 배경: 탑다운 판타지 섬 지도, 청록색 바다, 암석 해안, 숲과 산악, UI가 올라갈 수 있도록 가장자리 비네트, 텍스트 없음.
- 말판 이미지: 5x4 외곽 14칸 트랙, 3D 모델 모의전투가 가능한 중앙 평지 아레나, 캐릭터 피규어 디자인과 맞는 낮은 채도/데포르메 톤, 석재 타일과 금장 프레임, 앱 라벨을 올릴 수 있도록 텍스트 없음.
- 시작 배경: 어두운 해안 왕국, 성채와 바다, 황금빛 저녁 조명, 중앙/좌측 텍스트 공간, 텍스트 없음.
- 전투 결과 배경: 해안 왕국 전장 이후, 검과 깃발, 연기와 따뜻한 림라이트, 텍스트 오버레이용 어두운 가장자리, 텍스트 없음.
