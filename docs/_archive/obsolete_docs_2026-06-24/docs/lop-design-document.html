LOP — Land of Power

작성일: 2026-04-21  ·  최종 업데이트: 2026-05-04  ·  v0.4.0

1. 게임 개요

장르
전략 보드게임
모노폴리 메카닉 참조, IP 무관
판 크기
14칸
초소형 — 10~20분/판
플레이어 수
1~4인
vs AI (추후 멀티)
승리 조건
상대 파산
골드 0 이하 → 탈락
IP 독립성: LOP는 모노폴리 메카닉에서 영감을 받았으나, Hasbro 등과 어떠한 자산·명칭·디자인도 공유하지 않는 완전 독립 IP다.
의도적 소형 보드: 표준 모노폴리(40칸, 1~4시간)와 달리 14칸으로 축소해 1판을 10~20분 내에 완료. 모바일 세션 플레이 최적화.

3. 게임 플로우

게임 시작 → 캐릭터 선택 → 보드 시작
  └→ [매 턴]
       ├→ 주사위 굴림
       ├→ 이동할 말 1개 선택
       ├→ 선택한 말 이동
       └→ 칸 이벤트 처리
            ├→ 중립 땅: 전투 또는 골드 지불로 구매
            ├→ 내 땅: 건물 건설/업그레이드 + 병력 배치·징집
            ├→ 적 땅: 전투 또는 통행세 납부
            ├→ 적 말 조우: 말 전투 시뮬레이션
            ├→ 용병소: 골드로 용병 고용
            ├→ 찬스: 랜덤 이벤트 카드 즉시 발동
            └→ 출발점 통과: 골드·영토 생산 + 병사 고용 특전

4. 보드 레이아웃

5×4 외곽 14칸 구성. 플레이어(P)와 AI(E)는 대각선 반대편에서 시작.

[ P ] [땅1] [땅2] [용병] [땅3]
[땅4]                   [찬스]
[찬스]                  [땅5]
[땅6] [찬스] [땅7] [땅8] [ E ]
칸 종류수설명
출발 (P/E)2각자 시작점. 통과 시 골드·영토 생산 + 병사 고용 특전
일반 땅8게임 시작 시 중립 병력 배치. 전투 또는 구매로 점령
용병소2400골드로 랜덤 병종 2~8명 고용
찬스2착지 즉시 랜덤 이벤트 카드 발동

찬스 카드 (21종) — 착지 즉시 발동

모든 카드 착지 즉시 발동. 카드 슬롯 없음. 이동/상점 카드만 확인 버튼, 나머지 2초 자동 닫힘.
분류카드효과
즉시 골드골드 +200 / +400 / +600즉시 지급
즉시 병력병력 +3 / +5 / +8명말에 즉시 합류
징집긴급 징집 (300골드/10명), 무료 징병 6명즉시 처리
주사위다음 주사위 +2 / +4다음 롤에 적용
전투 강화공격력 1.5배 / 2배, 수비력 1.5배 / 2배다음 전투에 적용
경제 전략통행세 면제, 적 통행세 2배(1~2바퀴), 건설 50% 할인즉시 활성화
이동 / 특수원하는 칸 이동, 상점 이동, 적 땅 초기화즉시 실행

6. 병력 시스템

항목내용
시작 병력말마다 25명 (검사 10 + 궁수 8 + 창병 7)
한 바퀴 고용 특전출발점 통과 시 골드로 병사 고용 가능 (LapBonusModal)
영토 자동 생산한 바퀴 완주 시 내 영토마다 자동 증가 (기본 1명 + 병영 보너스)
전투 점령 자동 배치전투 승리 시 기본 5명(검사) 즉시 배치 → 추가 배치 선택
최대 보유말의 통솔력에 따라 결정
  • 말이 데리고 다니는 병력만 전투에 참여
  • 땅에 배치된 병력은 수비 전용
  • 내 땅 착지 시 병력 배치 또는 영토에서 징집 가능

6-1. 중립 병력 & 땅 점령

티어중립 병력구매가기본 통행세
Tier 1 (출발점 인근)1~3명200g120g
Tier 2 (중간)2~5명400g250g
Tier 3 (프리미엄)4~8명650g420g
점령 방법조건결과
전투병력 보유승리 시 점령. 기본 5명 자동 배치 후 추가 배치 선택
골드 구매충분한 골드즉시 점령. 중립 병력이 내 수비대로 전환
적 땅은 전투만 가능. 골드 구매는 중립 땅에서만 허용.

8. 전투 시스템

전투 발생 조건

상황설명
영토 전투적 땅 또는 중립 땅 착지 → 수비 병력과 전투
말 전투같은 칸에 적 말 → 말끼리 + 보유 병력으로 전투

전투 계산

  • 매 라운드: 공격측 병력 × 공격력 배율 → 방어력으로 감소 후 적 병력 차감
  • 수비측 동시 반격. 병종 상성 카운터 보너스 적용
  • 강화 건물이 있으면 수비 병력 공격/방어 추가 보너스
승리: 기본 5명 자동 배치 → 말에서 추가 배치 선택
패배: 말이 병력 0으로 출발점 귀환
