## 1. 게임 개요

| 항목 | 내용 |
|------|------|
| 장르 | 전략 보드게임 (모노폴리 메카닉 참조, IP 무관) |
| 플랫폼 | 브라우저 (Next.js), 추후 Electron + 온라인 멀티 |
| 핵심 루프 | 주사위 굴림 → 말 선택 → 이동 → 칸 이벤트 → 전투/건설/구매 |
| 승리 조건 | 상대방을 파산(돈 0)시키기 |
| 패배 조건 | 돈이 0이 되면 탈락 |
| 플레이어 수 | 1인 vs AI (추후 온라인 멀티 확장) |
| 판 크기 | 14칸 (초소형) — 1판 목표 플레이타임 **10~20분** |

> **IP 독립성**: LOP는 모노폴리의 보드 순환·통행세·건설 메카닉에서 영감을 받았으나, 모노폴리 및 관련 IP(Hasbro 등)와 어떠한 자산·명칭·디자인도 공유하지 않는 완전 독립 IP다.

> **의도적 소형 보드 설계**: 표준 모노폴리(40칸, 1~4시간)와 달리 14칸으로 판을 대폭 축소해 1판을 10~20분 내에 완료할 수 있도록 설계했다. 모바일 세션 플레이에 최적화된 핵심 결정으로, 출퇴근·짧은 휴식 시간에도 완결된 게임 경험을 제공한다.

## 3. 게임 플로우

```
게임 시작 → 캐릭터 랜덤 선택 연출 → 보드 시작 (시작 배치)
  └→ [매 턴]
       ├→ 주사위 굴림 (2d4, 0~6 + 보너스)
       ├→ 이동할 말 1개 선택
       ├→ 선택한 말 이동 (애니메이션)
       ├→ [이동 경로 통과] 내 영토 지나칠 때 → 병력 징집 선택 (PassCollect)
       └→ 칸 이벤트 처리
            ├→ 중립 땅: 전투 또는 골드 지불로 구매
            ├→ 내 땅: 건물 건설/업그레이드 여부 선택
            ├→ 적 땅: 전투 또는 통행세 납부
            ├→ 적 말 조우: 말 전투 (수비대 합산)
            ├→ 용병소: 용병 계약 / 장수 고용 / 병력 구매
            ├→ 찬스: 랜덤 이벤트 카드 즉시 발동
            └→ 출발점 통과: 골드 +200 + 영토별 병력 자동 생산 + 캐릭터 스킬
```

**더블(Double)**: 두 주사위 눈이 같으면 턴 종료 후 보너스 턴 획득.

## 4. 보드 레이아웃

5×4 외곽 14칸 구성. 플레이어(P: index 0)와 AI(E: index 7)는 대각선 반대편에서 시작.

```
[P:왕도성문] [드래곤고원] [남부평원] [용병소] [황금계곡]
[북부고지]                              [운명의길:찬스]
[고갯길:찬스]                           [서쪽숲길]
[포호스강]   [용병시장]  [철광산맥] [동부항구] [E:변방요새]
```

| 칸 종류 | 수 | index | 설명 |
|---------|-----|-------|------|
| 출발 (P) | 1 | 0 | 플레이어 시작점. 통과 시 병력 생산·골드 지급 |
| 출발 (E) | 1 | 7 | AI 시작점. 통과 시 동일 효과 |
| 일반 땅 | 8 | 1,2,4,6,8,9,11,13 | 게임 시작 시 중립 병력 배치. 전투 또는 구매로 점령 |
| 용병소 | 2 | 3,10 | 용병 계약 / 장수 고용 / 병력 구매 |
| 찬스 | 2 | 5,12 | 랜덤 이벤트 카드 즉시 발동 |

> 세금(세금 칸)·커뮤니티 칸은 현재 미구현. 용병소가 상점 역할 담당.

**찬스 카드** (착지 즉시 발동, 25종):

| 분류 | 카드 | 수 |
|------|------|----|
| 즉시 골드 | +200 / +400 / +600 | 3 |
| 즉시 병력 | 말에 +3 / +5 / +8명 합류 | 3 |
| 징집 | 300골드→10명, 무료 6명 | 2 |
| 주사위 보너스 | 다음 주사위 +2 / +4 | 2 |
| 전투 강화 | 공격력 1.5배 / 2배, 수비력 1.5배 / 2배 | 4 |
| 경제 전략 | 통행세 면제, 적 통행세 2배(1바퀴/2바퀴), 건설 50% 할인 | 4 |
| 병력 배치 | 보유 영토에 랜덤 5명 / 8명 | 2 |
| 건물 지원 | 다음 건물 1채 무료 건설 | 1 |
| 드래곤 | 5바퀴 후 드래곤 출현 | 1 |
| 이동 / 특수 | 원하는 칸 이동, 용병소 이동, 랜덤 적 땅 초기화 | 3 |

> 모든 카드는 찬스 칸 착지 시 즉시 발동. 이동/용병소 카드는 확인 버튼 후 실행, 나머지는 즉시 적용 후 EventModal 표시.

## 5. 말(장수) 시스템

### 5.1 기본 능력치 & 고유 스킬

| 능력치 | 역할 |
|--------|------|
| `통솔력` | 데리고 다닐 수 있는 최대 병력 수 결정 |
| `고유 스킬` | 조건 충족 시 자동 발동되는 패시브 효과 |

게임 시작 시 캐릭터 **7종** 중 랜덤 1개 선택. 공격/방어 배율은 모두 동일(1.0×), 통솔력과 고유 스킬로 차별화.

| 캐릭터 | 통솔력 | 고유 스킬 | 스킬 효과 | 발동 조건 |
|--------|--------|----------|----------|----------|
| 해적 | 45명 | 약탈 | 골드 +100 | 전투 승리 시 |
| 선동가 | 40명 | 선동 | 랜덤 병종 2명 말에 합류 | 랩 완주 시 |
| 종교인 | 40명 | 축복 | 보유 영토에 랜덤 병종 3명 분배 | 랩 완주 시 |
| 장군 | 60명 | 전리품 | 랜덤 병종 1명 말에 추가 | 전투 승리 시 |
| 흑마술사 | 30명 | 저주 | 랜덤 적 말 병력 2명 소멸 | 랩 완주 시 |
| 밀수꾼 | 30명 | 밀수 | 골드 +200 | 랩 완주 시 |
| 사기꾼 | 25명 | 사기 | 골드 +200 | 주사위 합계 0 시 |

> 스킬은 별도 발동 없이 조건 충족 시 자동 적용됨.

### 5.2 말 고용

- 용병소 칸에서만 추가 고용 가능
- 고용 즉시 해당 플레이어의 출발점에서 등장

| 고용 순서 | 비용 |
|----------|------|
| 1번째 | 무료 (시작 지급) |
| 2번째 | 500 |
| 3번째 | 1,200 |
| 4번째 | 2,000 |
| 5번째 | 5,000 |
| N번째 | 이전 비용 × 2 + 300 |

### 5.3 턴 진행

- 매 턴 주사위 2d4를 굴림 (각 0~3, 합계 0~6)
- 보유한 말 중 **1개를 선택**해서 이동
- 전투 패배 시 해당 말은 병력 0으로 출발점 귀환 (소멸 없음)
- 더블(양 주사위 동일): 해당 턴 이후 보너스 턴 획득

## 6. 병력 시스템

### 6.1 병종 (6종)

| 병종 | 이모지 | 공격 | 방어 | 가격 | 상성(강한 상대) | 비고 |
|------|--------|------|------|------|----------------|------|
| 검사 | ⚔️ | 1.1× | 1.0× | 60G | 창병 | 기본 균형형 |
| 궁사 | 🏹 | 1.5× | 0.5× | 80G | 검사·창병 | 고공격·저방어 |
| 기마병 | 🐎 | 1.4× | 0.7× | 120G | 검사·궁사 | 창병에 취약 |
| 창병 | 🔱 | 0.6× | 1.6× | 70G | 기마병 | 저공격·고방어 |
| 암살자 | 🥷 | 0.7× (말전투 3.8×) | 0.4× | — | — | 용병소 전용. 말 전투 시 극강 |
| 광전사 | 🪓 | 2.8× | 0.15× | — | — | 용병소 전용. 상성 없음. 고공격·극저방어 |

**상성 보너스**: 아군이 적의 약점 병종을 보유할 때 공격력 보너스(+최대 60%, 구성 비율 비례) 자동 적용.

### 6.2 병력 운용

| 항목 | 내용 |
|------|------|
| 시작 병력 | 말마다 20명 (검사 15 + 궁사 5) |
| 최대 보유 | 말의 통솔력에 따라 결정 (사기꾼 25 ~ 장군 60) |
| 영토 자동 생산 | 한 바퀴 완주 시 내 영토마다 baseLapProduction + 병영 보너스 자동 증가 |
| 전투 점령 자동 배치 | 전투 승리 시 기본 5명(검사) 즉시 배치됨 |
| 이동 중 징집 | 내 땅을 지나칠 때 PassCollect 모달 → 원하는 만큼 말에 징집 가능 |

- 말이 이동할 때 데리고 다니는 병력만 전투에 참여
- 땅에 배치된 병력은 수비 전용
- 내 땅 착지 시 말에서 땅으로 배치 또는 땅에서 말로 징집 가능

## 6-1. 중립 병력 & 땅 점령 시스템

### 게임 시작 시 중립 병력 배치

8개 일반 땅은 게임 시작 시 중립 병력이 **Tier별 랜덤 구성**으로 배치됨:

| Tier | 해당 index | 병력 범위 | baseLapProduction 범위 |
|------|-----------|---------|----------------------|
| Tier 1 (저가) | 1, 2 | 3명 (고정) | 1~2 |
| Tier 2 (중가) | 4, 6, 8 | 3~5명 | 2~4 |
| Tier 3 (고가) | 9, 11, 13 | 5~7명 | 3~6 |

중립 병력 구성은 Tier에 따라 랜덤 병종 1~2종 혼합.

### 동적 가격 산정

땅 가격과 기본 통행세는 게임 시작 시 `baseLapProduction`으로 결정됨:

- **땅 구매가** = baseLapProduction × 120
- **기본 통행세** = baseLapProduction × 80
- **통행세 스케일**: `기본통행세 × (1 + lapCount × 0.12)`, 10 단위 반올림

→ 같은 Tier 내에서도 생산력 높은 땅이 비싸다.

### 땅 점령 방법 (2가지 선택)

중립 땅 또는 적 땅 착지 시 선택:

| 방법 | 조건 | 결과 |
|------|------|------|
| **전투** | 병력 보유 | 시뮬레이션 진행. 승리 시 점령 |
| **골드 구매** | 충분한 돈 | 전투 없이 즉시 점령. 비용 = 땅 구매가 |

> 적 땅은 전투만 가능. 골드 구매는 중립 땅에서만 허용.

### 점령 시 병력 배치

전투 승리 직후:
1. **자동 배치**: 검사 5명 기본 배치 (공격 측 비용 없음)
2. **추가 배치**: 말 보유 병력에서 원하는 만큼 추가 배치 가능

## 6-2. 드래곤 시스템

### 드래곤 등장

찬스카드 "드래곤의 각성" 발동 시:
1. `dragonPending` 상태 기록 (summonAtLap = 현재 랩 + 5)
2. 이후 lapCount가 summonAtLap에 도달하면 드래곤 등장
3. 등장 위치: **적 소유 땅 중 가장 비싼 땅** (없으면 중립 고가 땅)

### 드래곤 스탯

| 항목 | 값 |
|------|----|
| 초기 병력 | 30명 |
| 공격력 | 1.8× |
| 방어력 | 1.2× |

### 드래곤 행동

- **턴 종료마다** 1~3칸 랜덤 이동
- 이동한 칸에 수비대가 있으면 자동 교전 (1라운드 즉시 처리)
  - 드래곤·수비대 동시 피해, 둘 다 병력 감소
  - 드래곤 병력 0 → 소멸
- 플레이어 말이 드래곤이 있는 칸에 착지 → 드래곤과 전면 전투 강제 발생

### 드래곤 전투 결과

| 결과 | 효과 |
|------|------|
| 승리 | 골드 +800, 랜덤 병종 5명 획득. 드래곤 소멸 |
| 패배 | 말이 병력 0으로 출발점 귀환. 드래곤 잔존 병력 유지 |

## 7. 건물 시스템

땅 구매 후, **자기 땅 칸에 착지했을 때** 건설/업그레이드 선택 가능.
땅 1칸당 1종류 선택. 같은 종류로만 Lv3까지 업그레이드.
땅을 빼앗기면 건물째 새 주인에게 귀속.

> **무료 건설**: '왕실 지원' 찬스카드 획득 시 다음 건물 1채 비용 면제.

### 경제 건물 — 금고 (돈 생산)

| 등급 | 비용 | 한 바퀴 수입 | 통행세 |
|------|------|------------|--------|
| Lv1 금고 | 200 | +80 | 150 |
| Lv2 은행 | 500 | +200 | 300 |
| Lv3 왕실 금고 | 1,000 | +400 | 550 |

### 병력 건물 — 병영 (병력 생산)

| 등급 | 비용 | 한 바퀴 추가 생산 | 통행세 |
|------|------|----------------|--------|
| Lv1 병영 | 200 | +2명 | 150 |
| Lv2 훈련소 | 500 | +5명 | 300 |
| Lv3 대병영 | 1,000 | +10명 | 550 |

> 병영 보너스는 baseLapProduction에 더해진다. (예: baseLapProd=3 + Lv1병영 = 5명/랩)

### 강화 건물 — 초소 (수비 강화)

| 등급 | 비용 | 수비 공격 보너스 | 수비 방어 보너스 | 통행세 |
|------|------|--------------|--------------|--------|
| Lv1 초소 | 200 | 1.10× | 1.05× | 300 |
| Lv2 성벽 | 500 | 1.20× | 1.15× | 600 |
| Lv3 요새 | 1,000 | 1.35× | 1.30× | 1,200 |

## 8. 전투 시스템

### 8.1 전투 발생 조건

| 상황 | 설명 |
|------|------|
| **영토 전투** | 적 땅에 착지 → 그 땅의 수비 병력과 전투 |
| **말 전투** | 같은 칸에 적 말과 겹침 → 적 말 병력이 수비대에 합산 |
| **드래곤 전투** | 드래곤이 있는 칸에 착지 → 드래곤과 강제 전투 |

### 8.2 전투 vs 통행세 선택 (적 땅)

- **전투**: 시뮬레이션 진행, 승리 시 점령
- **통행세**: 건물 등급 + lapCount 스케일 금액 납부 (전투 없이 통과)
- 패배 시에도 통행세 차감 (전쟁 배상)

### 8.3 전투 계산

```
매 라운드:
  공격 피해 = ceil(공격측병력 × 공격력배율 × 0.35 / 방어측방어배율)
  수비 피해 = ceil(수비측병력 × 수비력배율 × 0.35 / 공격측방어배율)
  → 둘 다 동시 적용 (선 공격 없음)
  → 먼저 병력 0이 되는 쪽 패배
```

**상성(Counter) 보너스**: 공격측이 수비측 약점 병종을 보유 시 공격력 보너스:
```
bonus = Σ (아군 해당병종비율 × 적군 약점병종비율 × 0.6)
최종 공격력 배율 × (1 + bonus)
```

**강화 건물 보너스**: 초소/성벽/요새는 수비 측 공격·방어 배율 추가 적용.

### 8.4 전투 결과

**승리 시**: 공격자가 남은 병력 중 원하는 만큼 배치해야 점령 확정 (기본 5명 자동 배치)
**패배 시**: 말이 병력 0으로 출발점 귀환 + 통행세 납부

### 8.5 전투 시뮬레이션 화면

```
[공격측]              VS         [수비측]
 말 이름                          수비대 / 적 말
 병력: 15명                       병력: 8명
 공격력 1.3×                      방어력 0.9×
```

## 9. 이동 중 영토 통과 (PassCollect)

플레이어 말이 이동 도중 **자신 소유 영토를 지나칠 때** 발동:

1. 이동 경로 중 통과한 내 땅 목록 자동 집계
2. PassCollect 모달 표시:
   - 통과한 각 영토의 주둔 병력 및 구성 표시
   - 슬라이더로 징집 수량 선택 (0 ~ 최대 용량 이하)
   - "징집" 클릭 → 말에 병력 추가, 해당 영토 병력 감소
   - "지나가기" 클릭 → 아무 변화 없이 진행

> AI는 자동으로 최대 용량까지 자동 징집.
> 말이 착지한 칸(목적지)의 병력은 수동 배치/징집 대상이며 PassCollect 대상이 아님.

## 11. 용병소 시스템

용병소 칸(index 3, 10) 착지 시:

1. **용병 계약** (400G): 랜덤 병종·랜덤 수량의 용병 1부대 획득
   - 병종: 일반 4종(가중치 2) + 암살자·광전사(가중치 1각) 총 10개 풀에서 랜덤
   - 수량: 2~8명 (제곱분포, ~61%가 2명, ~4%가 8명)
   - 획득 후 선택: 말에 합류 OR 내 영토(클릭 선택)에 배치
2. **장수 고용** (비용표 참조): 새 말 고용, 출발점에서 등장
3. **병력 구매**: 일반 4종 구매 가능 (암살자·광전사 불가)

## 12. AI 시스템

### 난이도 3단계

| 난이도 | 행동 방식 |
|--------|----------|
| 쉬움 | 이동할 말 랜덤 선택. 구매·건설은 랜덤 확률 결정 |
| 보통 | 상황별 우선순위 규칙 적용 |
| 어려움 | 보통 규칙 + 플레이어 자원 상태 파악 후 최적 행동 |

### 보통·어려움 AI 우선순위 규칙

| 상황 | AI 행동 |
|------|--------|
| 빈 땅 착지 | 병력 우세 시 전투, 골드 여유 있으면 구매 |
| 자기 땅 착지 | 병력 부족 시 병영, 돈 부족 시 금고 우선 건설 |
| 적 땅 착지 | 병력 우세 + 통행세 부담 크면 전투, 열세 시 통행세 |
| 돈 부족 | 병력 구매 자제, 통행세 선택 |
| 용병소 | 말 병력 부족 + 골드 여유 시 용병 계약 |
| 영토 3개+ (어려움) | 2번째 말 고용 고려 |
| 3인+ (어려움) | 말 최대 3개까지 고용 |

### AI 턴 처리 순서
1. 주사위 굴림
2. 규칙에 따라 이동할 말 1개 선택
3. 이동 및 칸 이벤트 자동 처리
4. 전투 발생 시 시뮬레이션 자동 완료 (800ms 딜레이 후 BATTLE_FINISH)

| 시즌 초 | 신규 캐릭터 프리뷰·스킬 공개 | 사전 보석 적립 → 출시 즉시 과금 유도 |
| 시즌 말 | 해당 시즌 한정 캐릭터 뽑기 종료 | FOMO → 막판 과금 스파이크 |
| 콜라보 시즌 | IP 협업 한정 캐릭터·보드 출시 | 비정기 대형 매출 이벤트 |

---

### 14.9 BM 원칙

1. **Pay-to-win 금지** — 보석으로 게임 내 골드·병력·전투력 직접 구매 불가
2. **광고 강제 노출 금지** — 모든 광고는 유저 선택형
3. **핵심 루프 무료 제공** — 결제 없이 게임의 재미 충분히 체험 가능
4. **확률 투명 공개** — 뽑기 확률 인게임 전면 표시 (한국 게임법 준수)
5. **원스토어 호환 고려** — 한국 앱 마켓(원스토어) 정책 준수
6. **콜라보 P2W 방지** — 콜라보 한정 캐릭터도 기존 캐릭터와 스탯 동급 유지
