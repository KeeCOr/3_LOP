# IARC 등급 심사 응답 가이드 — Lord of Poly

> Steam / Google Play / App Store 공통으로 사용하는 IARC (국제 연령 등급 연합) 설문 응답 가이드입니다.
> Steam의 경우 Steamworks 파트너 페이지 > 스토어 > 기본 정보에서 IARC 설문을 진행합니다.

---

## IARC 설문 응답

| 카테고리 | 질문 | 응답 | 근거 |
|---------|------|------|------|
| **폭력** | 폭력적 콘텐츠가 있습니까? | **예 (경미)** | 병력 전투 시뮬레이션 — 숫자/텍스트 결과, 그래픽 폭력 없음 |
| **폭력** | 피/고어 묘사가 있습니까? | **아니오** | 전투 결과는 골드/병력 수 변화로만 표현 |
| **폭력** | 현실적 폭력 묘사가 있습니까? | **아니오** | 추상적 보드게임 형태 |
| **성적 콘텐츠** | 성적 콘텐츠가 있습니까? | **아니오** | — |
| **언어** | 욕설이나 비속어가 있습니까? | **아니오** | — |
| **도박** | 실제 화폐 거래가 있습니까? | **아니오** | 찬스 카드는 인게임 이벤트만, 실제 머니 없음 |
| **도박** | 도박 시뮬레이션이 있습니까? | **아니오** | 랜덤 이벤트는 도박 메커닉이 아님 |
| **약물** | 약물/음주 묘사가 있습니까? | **아니오** | — |
| **공포** | 공포/혐오 요소가 있습니까? | **아니오** | — |
| **온라인** | 온라인 기능이 있습니까? | **아니오** | 완전 오프라인 (싱글플레이어 vs AI) |
| **인앱 구매** | 유료 아이템 구매가 있습니까? | **아니오** | — |
| **위치 정보** | 위치 정보를 수집합니까? | **아니오** | — |

## 예상 등급 결과

| 기관 | 예상 등급 |
|------|---------|
| **PEGI (유럽)** | PEGI 3 또는 PEGI 7 |
| **ESRB (북미)** | E (Everyone) |
| **GRB (한국)** | 전체 이용가 |
| **Google Play** | 모든 연령 |
| **App Store** | 4+ |

## 심사 진행 경로

### Steam
1. Steamworks 파트너 대시보드 → 해당 앱 선택
2. 스토어 페이지 → 기본 정보 → "IARC 등급 설문" 버튼 클릭
3. 위 표의 내용대로 응답 → 자동으로 각국 등급 생성
4. 생성된 등급 이미지가 Steam 스토어 페이지에 자동 표시

### Google Play
1. Play Console → 앱 콘텐츠 → 연령 등급
2. "설문지 시작" → 카테고리 선택: **게임**
3. 위 표의 내용대로 응답
4. 등급 확인 후 저장

### App Store (iOS)
1. App Store Connect → 앱 정보 → 연령 등급
2. 각 카테고리별 수위 선택 (없음 / 경미 / 중간 / 심함)
3. Lord of Poly는 대부분 "없음", 폭력만 "경미" 선택
